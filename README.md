# 🏛️ Plateforme ELT - UDL-SBA

Application de gestion d'emploi du temps et suivi d'assiduité pour le département d'Électrotechnique.

## ✨ Fonctionnalités principales

### 📊 Suivi d'Assiduité
- 📋 Saisie des absences
- 📊 Statistiques en temps réel
- 📈 Génération de rapports
- 👥 Répertoire des étudiants
- 🔔 Système d'alertes

### 📅 Gestion des EDTs
- 📅 Création et modification d'emplois du temps
- 👨‍🏫 Gestion des enseignants
- 🎓 Gestion des promotions et groupes
- ⚙️ Paramètres d'administration

### 🧠 EDT Intelligent
- 📊 Affichage optimisé des EDTs
- 🔍 Recherche avancée
- 📤 Import/Export de données
- 📊 Analytics et statistiques

## 🛠️ Technologie

- **Frontend** : Streamlit
- **Backend** : Python
- **Base de données** : Supabase (optionnel)
- **Exports** : Excel, PDF, Word

## 📋 Prérequis

- Python 3.8 ou plus
- pip (gestionnaire de paquets Python)

## 🚀 Installation locale

### 1. Cloner le repo
```bash
git clone https://github.com/VotreNom/mon-app-edt.git
cd mon-app-edt
```

### 2. Créer un environnement virtuel
```bash
python -m venv venv
source venv/bin/activate  # Sur Windows: .\venv\Scripts\Activate.ps1
```

### 3. Installer les dépendances
```bash
pip install -r requirements.txt
```

### 4. Lancer l'application
```bash
streamlit run Emploi_du_temps_COMPLET_AVEC_SIDEBAR.py
```

### 5. Ouvrir dans le navigateur
```
http://localhost:8501
```
